Claude Code was used in the creation of this project as per the assignment description. This was done by providing the requirements to the model and creating a planning document.

The planning document was then proof read to ensure best practices and altered to cover any mistakes that were left by the AI model. Such as not including any test cases in the original run.

The implementation was then done by Sonnet 5.5 to save on token costs and to ensure that the model would follow exact directions without deviating from the plans.

Claude Code was also used for test case generation, and then finally to push the code to GitHub for the final submission.
